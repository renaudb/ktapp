Use this skill to import core weapon rules from PDF as a JSON file. To do so, process the PDF and extract the structure below into a JSON file. Store weapon rules under `rules/weapon-rules.json`.

# Structure

Weapon rules have a name (e.g. Balanced) and a rule. Certain names are parameterized (e.g. Accurate x where x ).
